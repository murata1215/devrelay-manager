# 2026-09-05 17:49 JST ｜ サイクル1.33: フェーズ1 最終 E2E（添付実経路・1件のみ）

## 要求

1.32 の調査で判明した「添付コードパスは実経路で一度も実行されていない」という事実を受け、
manager の正規送信経路 → server → core → Agent の添付実経路を、小さなテキストファイル1件で
通しで検証する。成功条件は「Agent が添付の原文を実際に読み取れたことを確認できること」
（Plan 本文に仕込んだ一意トークンが現れること）。manager UI の貼り付け・プレビュー・送信成功は
人間による実機確認済みのため対象外とし、本サイクルは server → core → Agent の経路のみを扱う。

認証は既存の正規経路（core AuthSession 相乗り）を使うこと、迂回しないこと、通せなければ
そこで停止して報告することが厳守事項として指定された。ソース変更・新規ファイル作成は禁止で、
例外は「1KB未満の一時テキストファイル1件」と「本 devlog」のみ。
