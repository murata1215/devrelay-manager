# 2026-09-04 06:44 JST ｜ サイクル1.25: UI刷新② DispatchCard再設計とMarkdown

## 背景

サイクル1.23（Tailwind 導入）は「DispatchCard.tsx は触らない」制約のもと、旧クラス名22種を色だけトークン化して暫定移植していた。サイクル1.24（会話返答の永続化修正）で `routes/orchestrator.ts` に手を入れた際もこの暫定 CSS は据え置きのままだった。今回はその両方を正式に整理し、Markdown 描画・ProjectPicker の折りたたみもあわせて導入する。

## やったこと

- **react-markdown 導入**: `apps/web/package.json` に `react-markdown@^10.1.0` / `remark-gfm@^4.0.1` を追加。新規 `src/components/Markdown.tsx` は `.md` ラッパー div + `remarkGfm` + `components={{ a }}`（`target="_blank" rel="noopener noreferrer"`）で構成。v10 で廃止された `className`/`linkTarget` props は使わず、生 HTML はプラグイン未追加のため描画されない。
- **DispatchCard.tsx 全面書換**: カードは `surface` + 1px border + `rounded-lg`（12px）、影なし。`lib/dispatch-status.ts` の `statusToneOf`（5トーン: wait/run/ok/ng/unknown、変更禁止）をコンポーネント側で `success/warning/danger/neutral` の4系統バッジへ写像。`cardKindFor` は failed/stopped も `'progress'` に含めてしまうため、**スピナーは `tone==='run'`、danger 帯（statusReason）は `tone==='ng'`** で出し分け、kind 単体では判定しない（失敗した Dispatch がスピナーのまま固まる事故を回避）。ボタンは primary/secondary/text-danger の3種のみをローカル定数化。`window.confirm` を全廃し、`useState<PendingConfirm | null>` によるインライン確認バー（メッセージ＋実行/戻す）に置き換え。draft の textarea は `rows={10}` + monospace、awaiting_approval は summary/planMarkdown を `<Markdown>` 化しノイズ行のみ `<pre>` のまま、done は2カラム `dl`、stale は1行+再取得ボタン。
- **ProjectPicker.tsx 全面書換**: 既定は1行（フィルタ入力＋選択チップ×＋「候補を表示」）。ポップオーバーは `absolute bottom-full`（DOM はコンポーネント内、portal 不使用）、`max-h-60 overflow-y-auto`（240px）。オフラインは既定非表示で `showOffline` トグルを追加。旧2行の説明文を削除し placeholder を「投げ先のヒント（未選択でも送信可）」に変更、注記は wrapper の `title` へ移動。**props インターフェースは無変更**（`projects`/`selectedIds`/`onChange`）。
- **Timeline.tsx**: manager 発言を `<Markdown>` 化、「あなた」/「manager」ラベルを吹き出し外・muted 12px 相当に。末尾センチネル div + `useEffect` + `scrollIntoView({ block: 'end' })` で新着自動スクロール（親の `overflow-y-auto` はスクロール祖先として機能するため App.tsx 側の変更は不要）。
- **App.tsx**: **className/wrapper のみ**変更。タイムラインの外側ラッパーに `min-h-full flex flex-col justify-end` を付与し、メッセージが少ない時は下詰めになるようにした（プレースホルダ文言には `m-auto` を付けて中央寄せを維持）。ポーリング `useEffect`（L98-117）と `pollTimerRef` は無変更。
- **styles.css**: `.dispatch-card*`/`.badge*`（旧 L101-238）を全削除し、`--info`/`--council-badge` トークンを `:root`/dark/`@theme inline` の3箇所から削除。代わりに `.md` タイポグラフィ（本文15px、`code` は monospace + surface 背景 + 6px 角丸、`table` は1px border、リンクは accent 色下線）を追加。

## 発見・注記

- Tailwind v4 の `@theme inline` は `--radius-*` 系トークンから `rounded-*` ユーティリティを自動生成するため、`.dispatch-card` が手書きしていた `border-radius: var(--radius-lg)` は Tailwind の `rounded-lg` クラス1つに置き換えられた。
- ビルド後 JS サイズの増加（+162KB）は react-markdown が内部で unified/remark/mdast 系ツールチェーンを同梱するため。プレーンテキストのみのタイムラインに比べ相応のコストだが、要求Aの明示的な依存追加のため許容範囲と判断した。
