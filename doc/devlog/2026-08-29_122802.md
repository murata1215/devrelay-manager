# 2026-08-29 12:28 JST ｜ サイクル1.21: council結線

## 要求

council（claude=提案者、codex=批評者、既定OFF・opt-in）のチェックボックスがweb側に「枠」だけ先行して置かれていた実態（`disabled`固定・state無しの完全なダミー）を解消し、「webチェック → orchestrateリクエストbody → Dispatch永続化 → core submit引数の組み立て」までをmanager側で一気通貫に結線する。core自体は変更しない前提で、core側に受け口があるかを実測してから範囲を確定する。

## 実行

まず実core MCP（127.0.0.1:3005/mcp）へ`tools/list`を実呼び出しし、`submit_instruction`のinputSchemaが`projectId`/`instruction`の2つしか受け付けないこと（1.19で足した`note`すら実は受け取れていなかったこと）を確認した上で実装範囲をmanager側の結線のみに確定。web側はComposerのチェックボックスをuseState化しonSendへ渡し、`lib/orchestrate-body.ts`を新設して`council:true`のときだけキーを足す純関数に切り出した（1.20のapprove-plan-body.tsと同じ流儀、api.tsはimport.meta.env依存でnodeテストから触れないため）。server側は`orchestrateSchema`にcouncil受け口を追加、Dispatchに`council Boolean @default(false)`列をmigration 1本で追加、`draft-sink.ts`は`council===true`のときだけdataへ足す条件付き付与、`dispatch-view.ts`のDispatchDetail/serializeDispatchへ同時追加（#135機械照合対応）。core呼び出し側は`core/submit-args.ts`を新設し`buildSubmitInstructionArgs`でcouncil trueのときだけキーを足し、`coreClient.submitInstruction`と`dispatch-worker.ts`の`handleSubmitInstruction`まで貫通させた。DispatchCardにはcouncil trueのときだけ`badge--council`バッジを表示。

## 検証

`prisma migrate deploy`で`20260829122113_council`を適用しDB反映を実測、`prisma generate`実行。server側`pnpm test`は165 pass/0 fail、`pnpm typecheck`はエラーなし。web側`pnpm test`は29 pass/0 fail、`pnpm typecheck`は当初`lib/timeline.test.ts`のダミーDispatchオブジェクトに`council`が無くコンパイルエラーとなったため`council: false`を追加して解消、再実行で通過。`pnpm build`は208.58KB（gzip 66.06KB）で成功。`git diff --stat`で計21ファイル変更＋4新規ファイルのみでcore側・無関係ファイルへの差分が無いことを確認。

## 発見

core MCPの`submit_instruction`と`approve_implementation`のinputSchemaを`tools/list`で実測した結果、`submit_instruction`は`projectId`/`instruction`の2つ、`approve_implementation`は`projectId`/`submissionId`の2つしかrequired/propertiesに存在せず、1.19で追加した`note`も1.21で追加する`council`もcore側には受け口が一切無い。さらに`list_projects`に未知引数`council:true`を付けて実呼び出ししたところ正常応答が返り、coreは未知引数をエラーにせず静かに捨てる実装であることを確認した。このためcouncil=ONにしてsubmitしてもリクエスト自体は壊れないが、現時点でcore側の実際の挙動（claude↔codexの協議実行）は一切変わらない。web→server→DB→submit引数組み立てまでの結線は完了したが、協議を実際に起動させるには別途core側への受け口追加が必要であり、本サイクルの範囲外として明記する。
